02 · Qué hace

Todo lo que debe hacer un servidor local de modelos, en un solo binario.

Sin entorno de Python ni contenedores obligatorios. Instalas un paquete y tienes el servidor, la CLI y la app de escritorio.

Descarga desde cualquier sitio

El registro de Ollama, Hugging Face, catálogos git curados o el fichero GGUF y la carpeta que ya tienes. Descargas reanudables, en paralelo y verificadas por digest.

pullsearchimport

Carga bajo demanda

Los modelos se cargan con la primera petición y se descargan tras un keep-alive, así que los inactivos no consumen nada. Varios a la vez, en GPU, CPU o repartidos entre ambas.

GPU 100%Sin cargar

Elige el motor adecuado

llama.cpp para GGUF, el fork de PrismML para los modelos ternarios Bonsai, vLLM para safetensors, whisper.cpp para voz y stable-diffusion.cpp para imágenes.

CUDAVulkanROCmMetalCPU

Habla todas las APIs habituales

Ollama, OpenAI, Anthropic Messages y una API de decisiones en un mismo puerto. Los clientes, SDKs y agentes que ya usas funcionan cambiando solo la URL base.

ollamaopenaianthropic

Seguro de exponer

Desde la propia máquina no hace falta clave; desde cualquier otra, sí. Claves con permisos, caducidad y límite por modelo, TLS, registro de uso y auditoría.

Tiene app de escritorio

alkahest desktop abre una app nativa para explorar, descargar, ajustar y vigilar modelos, con icono en la bandeja. Usa la misma API que cualquier cliente.

06 · Un puerto, todas las APIs

Tus herramientas ya lo hablan.

Apunta cualquier cliente de Ollama, OpenAI o Anthropic a http://127.0.0.1:11435. El puerto 11435 es el siguiente al de Ollama, así que ambos pueden convivir.

Ollama native

POST/api/chat · /api/generate
POST/api/embed · /api/pull
GET/api/tags · /api/ps · /api/version

OpenAI /v1

POST/chat/completions · /responses
POST/embeddings · /rerank
POST/audio · /images
GET/models

Anthropic /v1

POST/messages · /messages/count_tokens

Decisiones /v1

POST/decisions · /systemone
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:11435/v1", api_key="unused-on-loopback")
reply = client.chat.completions.create(
    model="qwen3:8b",
    messages=[{"role": "user", "content": "Why is the sky blue?"}],
)
print(reply.choices[0].message.content)
curl http://127.0.0.1:11435/api/chat -d '{
  "model": "qwen3:8b",
  "messages": [{"role": "user", "content": "Hello"}]
}'

# cualquier cliente de Ollama: OLLAMA_HOST=127.0.0.1:11435
import anthropic

c = anthropic.Anthropic(base_url="http://127.0.0.1:11435", api_key="alk_...")
m = c.messages.create(
    model="qwen3:8b", max_tokens=200,
    messages=[{"role": "user", "content": "Hello"}],
)
# respuestas deterministas con probabilidades, puntuadas a partir de logits
curl http://127.0.0.1:11435/v1/decisions -d '{
  "model": "tev1:0.8b",
  "input": "I was charged twice for my order.",
  "questions": [
    {"type": "choice", "name": "route",
     "choices": [{"value": "billing"}, {"value": "shipping"}, {"value": "technical"}]},
    {"type": "predicate", "instructions": "Is the customer angry?"}
  ]}'

07 · Por dentro

Pequeño, rápido y comprobado en cada commit.

Escrito en Rust. La CI impone límites de tamaño y de tiempo de arranque, y cada release se compila y se prueba en Linux, macOS y Windows.

<30MiB
binario sin interfaz gráfica, con el motor de CPU al lado
50ms
arranque máximo de la CLI; serve listo en 500 ms
5
plataformas: Linux x64/arm64, macOS Intel/Apple Silicon, Windows
1.4k
tests automáticos, más conformidad con los SDKs oficiales

Subprocesos supervisados

Los motores hablan HTTP en su propio proceso. Un fallo nunca tumba el servidor, y un vigilante detiene los motores si el servidor muere.

Planificador

Admisión según la memoria estimada, expulsión de modelos inactivos, colas y slots paralelos por modelo, descarga tras keep-alive.

Almacén direccionado por contenido

Blobs por digest SHA-256, compartidos entre modelos y con recolección de basura. El store de Ollama se lee, nunca se escribe.

Detección de hardware

Instrucciones de la CPU, RAM, NVIDIA mediante NVML cargado en tiempo de ejecución, AMD, Vulkan y Metal: la build y el reparto adecuados.

Catálogos git

Recetas y modelos descargados por HTTPS, fijados a un commit y comprobados contra un índice de digests.

Escritorio nativo

GPUI, acelerado por GPU, en el mismo binario. Habla con el servidor por HTTP como cualquier otro cliente.

08 · Sirve a otras máquinas

Ábrelo a tu red sin abrirlo al mundo.

En local, sin fricción. Todo lo demás necesita una clave.

$ alkahest serve --host 0.0.0.0:11435
  • 01
    Claves de API con permisosInferencia o administración, limitadas a ciertos modelos y con caducidad. Guardadas como hashes con sal.
  • 02
    TLS integradoTu certificado o uno generado, recargado con SIGHUP.
  • 03
    API de administración segura ante navegadoresComprobación de Origin, Sec-Fetch-Site y Host contra CSRF y DNS rebinding.
  • 04
    Uso y auditoríaUso por clave, registro de peticiones sin contenido, métricas de Prometheus.
  • 05
    Se ejecuta como serviciosystemd, launchd o servicio de Windows, con un usuario dedicado.
