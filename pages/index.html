02 · What it does

Everything a local model server should do, in one binary.

No Python environment, no container required. Install a package, and the server, the CLI and the desktop app are there.

Downloads from anywhere

The Ollama registry, Hugging Face, curated git catalogs, or the GGUF file and folder you already have. Resumable, parallel, verified by digest.

pullsearchimport

Loads on demand

Models load on the first request and unload after a keep-alive, so idle models cost nothing. Several at once, on GPU, CPU or split between them.

GPU 100%Not loaded

Picks the right engine

llama.cpp for GGUF, the PrismML fork for ternary Bonsai models, vLLM for safetensors, whisper.cpp for speech, stable-diffusion.cpp for images.

CUDAVulkanROCmMetalCPU

Speaks every common API

Ollama, OpenAI, Anthropic Messages and a decision API on one port. Existing clients, SDKs and agents work by changing the base URL.

Safe to expose

Loopback needs no key; every other machine does. Scoped, expiring keys per model, TLS, usage records and an audit log.

Has a desktop app

alkahest desktop opens a native app to browse, download, tune and watch models, with a tray icon. It uses the same API as any client.

06 · One port, every API

Your tools already speak it.

Point any Ollama, OpenAI or Anthropic client at http://127.0.0.1:11435. Port 11435 is one above Ollama's, so both can run side by side.

from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:11435/v1", api_key="unused-on-loopback")
reply = client.chat.completions.create(
    model="qwen3:8b",
    messages=[{"role": "user", "content": "Why is the sky blue?"}],
)
print(reply.choices[0].message.content)
curl http://127.0.0.1:11435/api/chat -d '{
  "model": "qwen3:8b",
  "messages": [{"role": "user", "content": "Hello"}]
}'

# any Ollama client: set OLLAMA_HOST=127.0.0.1:11435
import anthropic

c = anthropic.Anthropic(base_url="http://127.0.0.1:11435", api_key="alk_...")
m = c.messages.create(
    model="qwen3:8b", max_tokens=200,
    messages=[{"role": "user", "content": "Hello"}],
)
# deterministic answers with probabilities, scored from logits
curl http://127.0.0.1:11435/v1/decisions -d '{
  "model": "tev1:0.8b",
  "input": "I was charged twice for my order.",
  "questions": [
    {"type": "choice", "name": "route",
     "choices": [{"value": "billing"}, {"value": "shipping"}, {"value": "technical"}]},
    {"type": "predicate", "instructions": "Is the customer angry?"}
  ]}'

07 · Under the hood

Small, fast, and checked on every commit.

Written in Rust. Budgets for size and start-up time are enforced by CI, and every release is built and tested on Linux, macOS and Windows.

<30MiB
headless binary, CPU engine shipped beside it
50ms
CLI start-up budget; serve healthy in 500 ms
5
release targets: Linux x64/arm64, macOS Intel/Apple Silicon, Windows
1.4k
automated tests, plus SDK conformance with the official clients

Supervised subprocesses

Engines speak HTTP in their own process. A crash never takes the server down; an orphan watchdog stops engines if the server dies.

Scheduler

Admission by memory estimate, eviction of idle models, per-model queues and parallel slots, keep-alive unload.

Content-addressed store

Blobs by SHA-256 digest, shared between models, garbage-collected. The Ollama store is read, never written.

Hardware detection

CPU features, RAM, NVIDIA through NVML loaded at run time, AMD, Vulkan and Metal: the right build and the right split.

Git catalogs

Recipes and model entries fetched over HTTPS, pinned to a commit, checked against an index of digests.

Native desktop

GPUI, GPU-accelerated, in the same binary. It talks to the server over HTTP like any other client.

08 · Serve other machines

Open it to your network without opening it to the world.

Loopback stays frictionless. Everything else needs a key.

$ alkahest serve --host 0.0.0.0:11435
  • 01
    API keys with scopesInference or admin, limited to some models, with an expiry. Stored as salted hashes.
  • 02
    TLS built inYour certificate or a generated one, reloaded on SIGHUP.
  • 03
    Browser-safe admin APIOrigin, Sec-Fetch-Site and Host checks against CSRF and DNS rebinding.
  • 04
    Usage and auditPer-key usage, request log without content, Prometheus metrics.
  • 05
    Runs as a servicesystemd, launchd or a Windows service, with a dedicated user.
