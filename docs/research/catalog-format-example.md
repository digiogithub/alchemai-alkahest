# Catalog format by example

Companion to [[ALK-SP-0011]] (Git-backed catalogs) and [[development/decisions/0006-catalog-fetch-strategy]].
Story [[ALK-US-0117]], epic [[ALK-EP-0015]]. The executable form of this example is the fixture
catalog `crates/alkahest-recipes/tests/fixtures/catalog/`, which the tests of [[ALK-US-0118]],
[[ALK-US-0119]], [[ALK-US-0120]] and [[ALK-US-0121]] load.

## Layout (R1)

```
catalog/                      the `subdir` of the source (`catalog` for the official one)
  catalog.toml                manifest (R2)
  index.toml                  generated file index (R8)
  engines/llama-cpp.toml      one recipe per engine id (R4, R5, R6)
  models/acme/assistant.toml  one entry per <namespace>/<model> (R7)
  README.md                   ignored, never fetched
```

## Manifest (R2)

```toml
schema_version = "1.0"        # MAJOR.MINOR; newer major refused, newer minor accepted
name = "fixture"
description = "Test catalog"
min_alkahest = ">=0.1.0"      # optional semver requirement
```

## Engine recipe extensions (R5, R6)

The recipe format of `recipes/*.toml` ([[ALK-SP-0003]] R3) plus:

```toml
[[variants."vulkan".dependencies]]   # downloaded with the variant (optional = false)
id = "vulkan-loader"
os = "windows"
arch = "x86_64"
url = "https://example.invalid/vulkan-1.dll"
sha256 = "..."                       # mandatory in git catalogs; tofu is local-only
size = 1500000
format = "file"                      # tar.gz | zip | file
dest = "."                           # relative to the engine install dir, no `..`
optional = false                     # true: only with --with <id> / --with-runtime (cuda-*)

[variants."cpu-native"]              # source-only, never auto-selected
accelerator = "cpu"
native = true                        # alkahest engines install llama-cpp --native
[variants."cpu-native".source]
git = "https://github.com/ggml-org/llama.cpp.git"
rev = "b11669"
cmake_flags = ["-DGGML_NATIVE=ON"]
```

`companions` keep parsing and are read as optional dependencies.

## Model entry (R7)

```toml
name = "acme/assistant"              # equals the path models/acme/assistant.toml
description = "..."
license = "apache-2.0"
tags = ["chat", "tools"]

[[variants]]                         # first variant = default tag
tag = "q4_k_m"
format = "gguf"                      # gguf (default) | safetensors
quant = "Q4_K_M"
engine = "llama-cpp"                 # optional; ALK-SP-0003.R2 when absent
template = "chatml"                  # or template_text + template_format = "jinja" | "go"
params = { num_ctx = 8192, temperature = 0.7 }
[[variants.files]]
kind = "model"                       # model | projector | adapter | vae | text-encoder | tokenizer | config
urls = ["https://mirror-a/...", "https://mirror-b/..."]   # or url = "..."
sha256 = "..."                       # mandatory
size = 24                            # mandatory
filename = "assistant-q4_k_m.gguf"   # optional
auth = "private.example.org"         # optional: token from the keyring for this host
```

Pulled as `catalog:acme/assistant[:q4_k_m]` or `catalog:<source>::acme/assistant:q4_k_m`
(R13); stored as `catalog/acme/assistant:q4_k_m` in the Alkahest store.

## Index (R8)

```toml
schema_version = "1.0"
[[files]]
path = "engines/llama-cpp.toml"
sha256 = "..."
size = 3011
```

Generated by `alkahest catalog index <dir>` or `cargo xtask catalog-check --fix`; CI fails on a
stale index.

## Source configuration (R9)

```toml
[[catalogs]]                         # the default when no [[catalogs]] is configured
name = "official"
url = "https://github.com/digiogithub/alchemai-alkahest"
ref = "main"
subdir = "catalog"
# pin = "<commit id>"                # freeze; no refresh
# refresh_interval = "24h"
# enabled = false

[[catalogs]]                         # later = higher layer (R12)
name = "acme"
url = "https://git.example.org/acme/catalog"
ref = "stable"
# token: keyring service "alkahest", user "catalog:acme" (never in this file)
```

Snapshots live in `<data_dir>/catalogs/<name>/` with `snapshot.toml` (`commit`, `fetched_at`,
`checked_at`, last error) (R10).

## Fixture notes

- Every URL uses the reserved `.invalid` TLD; tests point the source at a local server.
- Engine digests are synthetic (`111...`); only the `q4_k_m` model file has a real digest: it is
  `crates/alkahest-recipes/tests/fixtures/catalog-blobs/assistant-q4_k_m.gguf`, a 24-byte GGUF
  v3 header with no tensors and no metadata.
- `.gitattributes` forces LF, so the digests in `index.toml` hold on every platform.
- The current strict recipe parser rejects `dependencies` and `native` until [[ALK-US-0119]]
  lands; the fixture is input for that story, not for today's `Catalog::with_dir`.
