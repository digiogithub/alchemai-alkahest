Implemented in commit 5eb17b5 (branch worktree-agent-abb73525b7991e138, on top of ALK-US-0064 e4cc793).

- `alkahest-desktop/src/connection.rs`: pure `Machine` (connecting / connected / starting / not running / unauthorized / error, backoff 0.5 s -> 10 s, start polling 0.5 s for 30 s, health every 10 s); `ServerApi` trait implemented for `alkahest_client::Client`; `ConnectionManager` on the tokio bridge following `/alkahest/v1/events`, `Command::{StartServer, Retry}` in, `Snapshot` (service card, card action, rail counters) out via `watch`.
- `launcher.rs`: systemd user unit if installed, else detached `alkahest [--config] [--host] serve`; Start offered only for loopback servers.
- `settings.rs`: `desktop.toml` (`server_url`, `theme`), API key from `ALKAHEST_API_KEY` or the OS keyring (`alkahest` / `desktop-api-key`).
- `alkahest-client`: additive `runtime_status()` and `events()` (SSE) with `SchedulerStatus`, `RuntimeModel`, `ServerEvent`.
- Shell: service card with Start server / Retry, live Library and Running counters.

Tests: scenario `connection::tests::no_server` (fake server + launcher, paused time) plus machine/backoff/card/launcher/settings/SSE tests; workspace nextest 763 passed, GUI tests 27 passed, clippy (both configs), deny, check-deps, tokens, machete, typos OK. End to end under Xvfb: "Service not running" -> click Start server -> `alkahest serve` started -> "Service running", counters filled.
