Implemented in commit baaedc0. Keys `alk_<8 id>_<52 secret>` (lower-case base32 from the OS CSPRNG, 260-bit secret), stored only as salted SHA-256 (16-byte salt, constant-time compare) in `ResolvedPaths::key_store` (JSON v1, 0600, lock file + temp + fsync + rename). Records: id, name, created, scopes (inference/admin; admin implies inference), optional model allowlist, optional expiry, revoked time. `FileKeyVerifier` re-reads the store when mtime/len/inode change, so a revoke applies to the next request (no cache needed). CLI: `keys create <name> [--scope] [--model] [--expires 30d|RFC3339]` (shown once), `keys ls`, `keys revoke <id|name>`. Decision: SHA-256 instead of Argon2 (random 260-bit secret; slow hash would only be a DoS amplifier) — recorded in docs/development/changes/2026-10-17-api-key-store.md with the security checklist. Security-tagged: needs product owner review.
