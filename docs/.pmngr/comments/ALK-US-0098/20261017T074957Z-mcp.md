Server and client part implemented in commit 1b5c205; the desktop tiles / live requests table are left for a later desktop story.

- `alkahest_sysinfo::UtilizationMonitor`: machine CPU % (persistent sampler), logical/physical cores, per-process-tree CPU, GPU busy %, memory-controller % and temperature via NVML (`nvmlDeviceGetUtilizationRates`, `nvmlDeviceGetTemperature`) and amdgpu sysfs.
- `alkahest_api::feed`: bounded ring (500) of `RequestRecord`s for every inference POST (time, route, family, model, caller key id/name or local, prompt/completion tokens, status, duration until the body ends, aborted) — never content. `GET /alkahest/v1/requests?last=60s&limit=`, SSE `request` events on `/alkahest/v1/events`.
- `GET /alkahest/v1/utilization`; `GET /alkahest/v1/ps` adds `utilization` and per-model `cpu_percent`.
- `POST /alkahest/v1/models/{name}/kill`: `Scheduler::kill`, `StopReason::Killed`, `EngineInstance::kill` (SIGTERM+SIGKILL to the process group at once).
- Client (new file `monitor.rs`): `recent_requests`, `utilization`, `kill_model`, `ServerEvent::request`; `RuntimeModel::cpu_percent`, `SchedulerStatus::utilization`.
- New workspace dep `http-body =1.1.0` (already locked via axum, MIT).
