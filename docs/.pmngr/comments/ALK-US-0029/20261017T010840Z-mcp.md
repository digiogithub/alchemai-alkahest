Implemented in commit 2ec8584 (branch worktree-agent-ab6bdf113fce9dca9).

- `admission` module: MemoryProbe / SystemMemoryProbe / StaticMemoryProbe, `usable`, `max_loaded` (0 = 3 per GPU or 3 on CPU), `placement` (estimator with the effective ctx, slots, KV types, FA, mmproj and free VRAM), `launch_gpu_layers` (automatic partial offload), `pick_victim` (LRU idle), `Accounted` (estimate raised to measured RSS).
- Admission runs under a load gate: fit, else evict the LRU idle model, else wait for a busy model up to load_timeout, else 503 `InsufficientMemory` with the estimate, or `TooManyModels`. A model that would not fit even with everything else unloaded fails at once.
- Tests: tests/admission.rs (11, incl. scenario `eviction`). Change record: docs/development/changes/2026-10-17-scheduler-admission-eviction.md
- Open: per-process VRAM through NVML is filed as an inbox item.
