Implemented in commit a696ada (branch worktree-agent-ab6bdf113fce9dca9).

- Each runner has a FIFO semaphore with num_parallel slots, and a Lease holds one slot. A global max_queue (default 512) counts requests that do not have a lease yet; overload returns `ServerBusy` (503 "server busy"). Dropped requests leave the queue without cancelling the load. A stop fails requests waiting for a slot; after a crash, requests waiting for a slot reload the model.
- Observability: `Scheduler::queued()`, `rejected()`, `queues() -> Vec<QueueStatus>`.
- Tests: tests/queue.rs (7, incl. scenario `queue_full`). Change record: docs/development/changes/2026-10-17-scheduler-queues.md
