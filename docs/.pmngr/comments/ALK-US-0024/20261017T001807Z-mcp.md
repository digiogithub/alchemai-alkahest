Implemented in commit ca61754 (branch worktree-agent-afeb30bfe5e79ef80), module alkahest-engine::supervisor.

- `launch(make_spec, &SpawnOptions)`: free loopback port (bind 127.0.0.1:0), pre-spawn check and retry on bind-failure exits; `spawn` without waiting.
- `EngineHandle`: wait_ready (health polling with timeout), exited, stop/stop_with_grace (SIGTERM to the process group, SIGKILL after grace; Windows TerminateProcess), subscribe (watch of `EngineState`), logs (ring buffer, tracing, optional per-model log file), resource_usage (RSS/CPU of the tree via sysinfo).
- Crash detection: `ExitInfo { code, signal, requested, stderr_tail }`; stragglers in the group are killed after any exit; dropping all handles stops the engine.
- `RestartTracker`/`RestartPolicy` crash-loop hook for the scheduler.
- New pin `rustix =1.1.5` (unix, safe killpg). Test binary `alkahest-fake-engine`.
- Tests: `tests/supervisor.rs` (14: ready, timeout, exit before ready, `crash`, kill, port collision before/after spawn, exhausted ports, escalation, group kill, drop, usage, library path) + unit tests; 5 consecutive runs green; ci-local green.
