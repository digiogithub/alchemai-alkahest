Implemented in commit 65dc5cc (branch worktree-agent-ab6bdf113fce9dca9).

- `Scheduler::snapshot() -> SchedulerSnapshot` with per-model `ModelStatus`: processor split and label (100% GPU / 100% CPU / x%/y% CPU/GPU), RAM/VRAM charged, estimated and sampled, context, keep_alive, expires_at, active/queued/total requests, token totals, tokens/s, load time, pid and port. Global counters cover loads, failures, evictions, crashes and rejected requests.
- `refresh_usage()` samples RSS (and process VRAM through the probe hook), `Lease::record_usage(Usage)` is the hook for token counts, `render_prometheus` / `Scheduler::prometheus()` produce text exposition 0.0.4 for /metrics, and `subscribe()` gives a change feed for the SSE stream.
- ALK-T-0100 (SSE endpoint) is left open for the API layer, which now has the hook it needs.
- Tests: tests/metrics.rs (6, incl. scenario `ps`). Change record: docs/development/changes/2026-10-17-scheduler-runtime-metrics.md
