Implemented in commit 7dbb045. `UsageTracker` (last_used, requests, prompt/completion tokens per key) flushed every second and on shutdown to `keys.usage.json` next to the key store (server-owned, so it never races `keys revoke`); `UsageRecorder::record_tokens` via `AppState::usage()` for the inference handlers. `AuditLog`: JSON lines at `<log_dir>/audit.jsonl` (time, request id, key id, client, method, path without query, status, outcome), off-thread, bounded queue, rotated 10 MiB x 5, 0600; key-authenticated and refused requests only, never keys or bodies. `auth.audit_log` switch. `keys ls` shows last_used/requests/tokens. Scenario test `last_used` (library) and end-to-end `last_used_shows_in_keys_ls_and_the_audit_log`. Change record: docs/development/changes/2026-10-17-key-usage-audit.md.
