Implemented in commit 5f67519 (branch worktree-agent-a55448737b34516ec; main merged in 0e850dc).

- `alkahest run <model> [prompt]`: one-shot for a prompt or piped stdin (`/api/generate`), interactive rustyline session otherwise (`/api/chat`, history in `<data_dir>/history`, model preloaded). `/bye`, `/clear`, `/set parameter|system|format|noformat|think|nothink|verbose|quiet`, `/show info|parameters|system|template|license|modelfile`, `/load`, `/?`, `"""` multi-line, Ctrl+C stops a generation. Flags `--format`, `--think[=level]`, `--hidethinking`, `--keepalive`, `--no-start`; `--verbose` = Ollama timing stats for `run`.
- Server down: nothing is started automatically; guidance printed, and on a terminal it offers to start `alkahest serve` in the background.
- `alkahest-client`: `Client::load`. Dependency `rustyline =18.0.1` (MIT, file history only).
- Tests: unit tests in `crates/alkahest/src/run_cmd.rs` (scripted REPL against a mock server), `crates/alkahest/tests/run.rs` (4), client `load` test; real engine one-shot and pty-driven interactive session with qwen2.5-coder:0.5b. Change record `docs/development/changes/2026-10-17-run-interactive-chat.md`.
