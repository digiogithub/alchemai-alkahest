Implemented in commit 0a56f16. `serve_with(listener, app, stop, ServeOptions, ShutdownHooks)`: on stop the listener closes, in-flight requests drain up to `server.shutdown_timeout_secs` (default 30), then `ShutdownHooks` run newest first, each bounded (15 s) — the scheduler registers engine teardown via `AppState::shutdown_hooks()`. `stop_signal()`: SIGINT/SIGTERM; Windows ctrl-c, ctrl-break, console close, system shutdown (cross-checked for x86_64-pc-windows-gnullvm). The Windows service stop (ALK-US-0045) should pass its own stop future. `alkahest serve` exits 0. Tests: `crates/alkahest-api/tests/shutdown.rs` (scenario no_orphans with a real child process, drain, drain timeout), `crates/alkahest/tests/serve.rs#sig{term,int}_stops_the_server_with_exit_code_0`.
