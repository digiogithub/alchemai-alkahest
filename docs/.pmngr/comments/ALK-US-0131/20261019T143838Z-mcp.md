Implemented in commit de261b8 (no server/API change; uses `active_keys` from `GET /alkahest/v1/settings/network`).

- The bind host is set by "Allow access from other machines" on screen 14 (Keys), so validation lives in `alkahest-desktop/src/keys.rs` (`bind_needs_key`, `NetworkDraft::patch`, `KeysState::toggle_remote`/`bind_blocked`). The toggle is refused with an inline explanation and a secondary "Create a key" button; nothing is saved.
- Detached `serve` stderr goes to `<log_dir>/desktop-serve.stderr.log`; `ServerLauncher::startup_failure` + `ConnectionManager::check_startup` surface the server's `error:` line as soon as the process exits during startup (systemd user unit: journal summary or a pointer to `journalctl --user -u alkahest.service`).
