Implemented on branch worktree-agent-ab6bdf113fce9dca9: commit fb6aafe, follow-up 7995d96 after merging main (slots now go through `LaunchRequest::num_parallel`).

- `alkahest_sched::Scheduler` (new / with_probe, acquire -> Lease, unload, unload_all, shutdown, loaded), `ModelBackend` + `CatalogBackend` (catalog -> effective settings -> EngineRegistry::plan -> supervisor launch), `EngineInstance` (implemented for EngineHandle), `SchedError::status_code()`.
- One load per model shared by concurrent first requests, and a client that disconnects does not cancel it. Keep-alive works as in Ollama: request > model > global, the latest request's value applies, 0 unloads after the request, a negative value keeps the model loaded. Load-setting changes drain and reload the model. Crashes go through the RestartTracker (backoff and CrashLoop 502), and stop/shutdown fail waiting requests with 503.
- Tests: tests/scheduler.rs (20, incl. scenarios single_load, idle_unload, crash, stop) and tests/end_to_end.rs (real catalog, registry and alkahest-fake-engine process). scripts/ci-local.sh passes.
